Up Project 08. AX
=================

네이버 지도에서 지역 + 키워드/필터로 검색해서, 리뷰 많은 가게를 자동으로 모아
엑셀로 정리해주는 프로그램입니다. 네이버 API 키가 필요 없고, 코딩을 몰라도
아래 두 단계만 하면 됩니다.

만든이: 김채윤, 김윤경, 정민정, 김선태, 홍지우 바이어


1. 파이썬(Python) 설치 (한 번만 하면 됨)
------------------------------------
이미 설치되어 있다면 건너뛰세요.

1) https://www.python.org/downloads/ 접속 -> "Download Python 3.x.x" 클릭
2) 설치할 때 맨 아래 "Add python.exe to PATH" 체크박스 꼭 체크하고
   "Install Now"


2. 실행
-------
config.py, naver_restaurant_scraper.py, launcher.py, requirements.txt,
start.bat, enrich.py 파일을 전부 같은 폴더에 넣고, start.bat을
더블클릭하세요. 그게 전부입니다.

- 처음 실행: 필요한 프로그램을 자동으로 설치합니다. 검정 화면이 몇 분 떠
  있는 게 정상이니 기다려주세요. 끝나면 브라우저 탭이 자동으로 열립니다.
- 그다음부터: 바로 브라우저 탭이 열립니다.

브라우저 화면에서 희망지역 / 검색키워드 / 필터 / 기준리뷰수를 원하는 대로
채우고(전부 선택 입력이지만 희망지역·검색키워드·필터 중 최소 하나는 입력)
"실행"을 누르면 됩니다. 끝나면 화면에 결과 표가 바로 뜨고, 같은 폴더의
Excel 폴더에도 파일이 저장됩니다. "Excel 파일 열기" 버튼으로 바로 열 수
있어요.

다 쓰셨으면 브라우저 탭을 닫으면 자동으로 꺼집니다.


(선택) 고른 브랜드만 추가 정보 수집하기
--------------------------------------
결과 중 일부만 골라서 구글 검색으로 대표번호/본사명/대표자명/채용연락처를
추가로 모으고 싶다면, 같은 폴더에서 아래 명령어를 실행하세요.

    python enrich.py

브라우저에 체크박스 화면이 뜨고, 원하는 곳만 체크해서 수집하면 원래 엑셀
파일에 새 컬럼으로 추가됩니다.


문제 해결
---------
- start.bat을 눌렀는데 반응이 없는 경우: 이전에 켰던 프로그램이 아직
  뒤에서 켜져 있을 수 있어요. 브라우저 주소창에 http://127.0.0.1:8899/를
  직접 입력해보세요.
- 캡차(사람 인증)가 뜨는 경우: config.py에서 HEADLESS = False로
  바꾸고 다시 실행하면 브라우저 창이 뜨는데, 거기서 한 번 직접 풀어주세요.
  이후로는 잘 안 뜹니다.
- 결과가 이상하거나 비어있는 경우: 로그창에 나오는 디버그 내용을 복사해서
  보내주시면 바로 고쳐드릴게요.
