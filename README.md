# 강남구 맛집 리뷰 1000개 이상 검색기

네이버 지도에서 특정 지역(기본값: 강남구) + 원하는 음식 종류로 검색한 뒤, 검색
결과 목록을 스크롤해서 최대한 많이 불러오고, 그 중 **리뷰 1000개 이상인 가게만**
보기 좋게 정리된 엑셀 파일로 저장해주는 프로그램입니다.

**네이버 API 키가 필요 없습니다.** 네이버 지도 화면을 직접 검색/스크롤해서
정보를 가져오는 방식이라 API 신청 절차가 아예 없어요.

코딩을 몰라도 따라할 수 있도록 순서대로 설명합니다. 순서대로 하나씩만 하시면 됩니다.

---

## 0. 미리 알아둘 것

- 이 프로그램은 **네이버 지도 웹페이지를 직접 열어서** 목록/상세 정보를 읽어옵니다.
  네이버가 공식적으로 제공하는 기능이 아니라서, 나중에 네이버가 화면 구조를 바꾸면
  이 부분이 작동하지 않을 수 있습니다. 그럴 땐 다시 알려주시면 고쳐드릴게요.
- 동작 순서: `지역 + 음식종류`로 검색해서 목록을 스크롤해 최대한 불러오고,
  **브랜드명/리뷰수/대표 리뷰는 목록 화면 글자에서 바로 뽑습니다.** 그 중
  **리뷰 수가 기준을 넘는 항목만 그 자리에서 클릭**해서 옆에 뜨는 상세 패널에서
  정확한 카테고리와 실제 지도 링크를 가져옵니다 (페이지를 새로 열지 않고 이미
  열려있는 목록에서 바로 클릭하는 거라, 기준 미달 가게가 안 넘어가면 상세 페이지에
  아예 안 들어가는 것보다는 조금 느리지만 예전 방식보다는 훨씬 빠릅니다).
  (주소는 목록/상세 화면 글자만으로는 진짜 주소인지 홍보 문구인지 구분이 잘 안 돼서 뺐습니다.)
- 대표 리뷰도 AI 요약이 아니라 목록에 보이는 리뷰 후기 한 줄을 그대로 가져온
  것입니다. 실행하면 처음에 "목록이 잘 읽히는지 확인용" 디버그가 나오는데,
  카테고리나 지도 링크가 이상해 보이면 복사해서 보내주세요.
- 서버에 너무 빠르게 요청하지 않도록 자동으로 잠깐씩 쉬면서 실행되므로, 가게 수가
  많으면 시간이 좀 걸립니다.

## 1. 파이썬(Python) 설치하기

이미 설치되어 있다면 이 단계는 건너뛰세요.

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 버튼 클릭해서 설치 파일 받기
3. 설치 파일 실행 시, **맨 아래 "Add python.exe to PATH" (또는 "Add Python to PATH")
   체크박스를 꼭 체크**한 뒤 "Install Now" 클릭
4. 설치 확인: 터미널(아래 2번 참고)을 열고 아래 명령어 입력
   ```
   python --version
   ```
   버전 번호(예: Python 3.12.1)가 나오면 성공입니다.

## 4. 필요한 프로그램 설치하기

**이 단계는 따로 안 하셔도 됩니다.** `start.bat`을 처음 더블클릭할 때 알아서

걸리고 그동안 검정 화면(cmd 창)이 떠 있는 게 정상입니다 - 진행 상황이 그 안에
그대로 나오니 닫지 말고 기다려주세요. 설치가 끝나면 화면이 자동으로 넘어갑니다.

## 5. 검색 조건 설정하기

`config.py` 파일을 메모장(또는 아무 텍스트 편집기)으로 열어서, 원하는 대로 바꾸세요.

- `DISTRICT`: 검색할 지역 (예: `"강남구"`, 비워두면 지역 조건 없이 검색)
- `PRODUCT_GROUPS`: 찾고 싶은 음식 종류를 자유롭게 리스트로 적으세요. 네이버 지도에
  검색했을 때 실제로 결과가 나오는 말이면 뭐든 됩니다. 예: `["한식"]`,
  `["퓨전한식", "고깃집"]` (비워두면 이 조건 없이 검색)
- `BRAND`: 특정 브랜드(가게 이름)만 찾고 싶을 때 적으세요. 예: `"스타벅스"` ->
  `DISTRICT`와 합쳐져 "강남구 스타벅스"로 검색해서 강남구 안 스타벅스 지점들을
  찾습니다. (비워두면 브랜드 조건 없이 검색)
- `MIN_REVIEW_COUNT`: 최종적으로 남길 최소 리뷰 개수 (비워두거나 0이면 리뷰 수와
  상관없이 전부 가져옵니다)
- `OUTPUT_FILE`: 결과 엑셀 파일 이름
- `MAX_LIST_PAGES`: 검색 결과 목록(페이지 1, 2, 3...)을 최대 몇 페이지까지 넘겨가며
  불러올지 (늘리면 더 많이 찾지만 오래 걸림)
- `HEADLESS`: 브라우저 창을 화면에 보이게 할지 여부 (자세한 설명은 파일 안 주석 참고)

## 6. 실행하기

이제 매번 `config.py`를 열어서 지역/검색어/리뷰수를 고칠 필요 없이, 입력 화면을
통해 실행할 수 있습니다. 이 입력 화면은 **사용자님의 기본 브라우저(엣지/크롬 등)에
새 탭으로 자동으로 뜨는 방식**입니다 - 뒤에서는 파이썬이 그대로 돌지만, 화면만
웹페이지처럼 보이는 거예요. URL을 직접 입력하실 필요는 없습니다.

**폴더 안의 `start.bat` 파일을 더블클릭하세요.** 그게 전부입니다.

- **처음 실행할 때**: 필요한 프로그램을 알아서 설치합니다. 검정 화면(cmd 창)이
  뜨고 몇 분 정도 걸릴 수 있어요 (인터넷 속도에 따라 다름). 설치가 끝나면
  브라우저 탭이 자동으로 열립니다. (Python 자체는 미리 설치되어 있어야 합니다 -
  1번 참고. Python이 없으면 안내 메시지가 뜹니다.)
- **그다음부터**: 설치를 다시 안 하고 바로 브라우저 탭이 열립니다.

브라우저 화면에는 **희망지역**(예: 강남구), **키워드**(예: 한식 - 여러 개는
콤마로 구분, 예: `한식, 고깃집`), **브랜드**(예: 스타벅스 - 특정 브랜드 지점들만
찾고 싶을 때), **기준리뷰수** 네 칸이 있습니다. **전부 선택 입력이라 비워둬도
되지만, 희망지역 / 키워드 / 브랜드 중 최소 하나는 입력해야 합니다.** 기준리뷰수를
비워두면 리뷰 수와 상관없이 다 가져옵니다.

몇 가지 조합 예시:
- 희망지역=강남구, 키워드=한식, 기준리뷰수=1000 -> 강남구의 리뷰 1000개 이상인
  한식집을 전부 찾습니다 (기존 방식).
- 희망지역=강남구, 브랜드=스타벅스 (키워드/기준리뷰수는 비움) -> 강남구 안의
  스타벅스 지점을 리뷰 수 상관없이 전부 찾습니다.
- 브랜드=교촌치킨 (나머지 다 비움) -> 지역 제한 없이 "교촌치킨"으로 검색되는
  곳을 찾습니다.

"실행" 버튼을 누르면 그 아래 로그창에 진행 상황이 그대로 출력됩니다. 가게 수가
많으면 몇 분 정도 걸릴 수 있습니다. 중간에 멈추고 싶으면 "중지" 버튼을 누르면
지금까지 모은 것만 저장하고 끝납니다.

**프로그램을 완전히 끄려면**: 결과가 나온 뒤 보이는 **"종료" 버튼**을 눌러주세요.
브라우저 탭만 닫으면 화면은 사라지지만 뒤에서 프로그램은 계속 조용히 켜져 있는
상태라서, 다음에 `start.bat`을 다시 눌러도 새로 안 열리고 기존 걸 다시 보여주기만
합니다 (오작동 아닙니다). 그래서 다 쓰셨으면 "종료" 버튼을 눌러 정리해주시는 게
깔끔합니다.

(참고: `config.py`에 있는 `MAX_LIST_PAGES`, `HEADLESS` 같은 값은 그대로
적용됩니다. 이 값들은 자주 안 바꾸는 값이라 화면에는 없어요. `config.py`에서
직접 바꾸면 됩니다.)

터미널에 직접 명령어를 입력하는 방식(예전 방식)도 여전히 됩니다. 이 경우
`config.py`에서 지역/검색어/리뷰수를 직접 바꾼 뒤 아래처럼 실행하면 됩니다.

```
python naver_restaurant_scraper.py
```

## 7. 결과 확인하기

실행이 끝나면 브라우저 화면 로그창 아래에 **결과 표가 그 자리에서 바로** 뜹니다
(브랜드명/키워드/카테고리/리뷰수/대표 리뷰/네이버지도주소 - 지도주소는 클릭하면
새 탭으로 그 가게 지도 페이지가 열립니다). 엑셀 파일을 열지 않아도 결과를 바로
훑어볼 수 있어요.

동시에 프로그램이 있는 폴더 안의 **`Excel` 폴더**(없으면 자동으로 만듭니다)
안에도 엑셀 파일이 항상 저장됩니다. 입력한 지역/검색어/리뷰수와 크롤링한 날짜에
맞춰 파일 이름이 자동으로 정해집니다
(예: `강남구_한식_리뷰1000개이상_250115.xlsx`, 맨 뒤 숫자는 `년월일` 두 자리씩).
같은 이름의 파일이 이미 있으면(같은 조건으로 같은 날 또 실행한 경우 등) 기존
파일을 덮어쓰지 않고 `(1)`, `(2)`처럼 번호를 붙여서 따로 저장합니다. 화면의
**"Excel 파일 열기"** 버튼을 누르면 그 파일이 바로 열립니다.

파일을 더블클릭해서 엑셀로 열어도 됩니다. 컬럼은 **브랜드명, 키워드, 카테고리,
리뷰수, 대표 리뷰, 네이버지도주소** 순서입니다. (키워드는 config.py에서 검색에 쓴
음식 종류, 네이버지도주소는 클릭하면 바로 그 가게의 지도 페이지로 이동하는
링크입니다. 브랜드명/키워드/카테고리/리뷰수 칸은 가운데 정렬되어 있습니다.)

보기 편하도록 1행(헤더)은 회색 배경, 전체 글꼴은 '나눔바른고딕OTF'로 되어 있고,
열 너비/행 높이도 내용에 맞춰 자동으로 조정됩니다. 만약 컴퓨터에 '나눔바른고딕OTF'
글꼴이 설치되어 있지 않으면 엑셀이 다른 글꼴로 대신 보여줄 수 있는데, 이 경우
"네이버 나눔글꼴"을 검색해서 무료로 설치하시면 됩니다.

## 8. (선택) 고른 브랜드만 추가 정보 수집하기

결과 중 일부 브랜드만 골라서, 구글 검색으로 **대표번호 / 본사명 / 대표자명 /
채용연락처**를 추가로 모을 수 있습니다. 파일을 저에게 다시 보내지 않아도, 이 PC
안에서만 진행되는 방식이에요.

```
python enrich.py
```

실행하면 (가장 최근에 만든 결과 엑셀을 자동으로 찾아서) 브라우저 창이 자동으로
열리고, 브랜드 목록이 체크박스로 나옵니다. 원하는 곳만 체크하고 "선택한 브랜드
수집 시작"을 누르면, 터미널 창에서 진행 상황이 보이고 끝나면 원래 엑셀 파일에
새 컬럼(대표번호/본사명/대표자명/채용연락처)이 추가됩니다.

**참고**: 이 기능은 구글 검색 결과와 회사 홈페이지/채용사이트(사람인 기준) 글자를
읽어서 만드는 거라, 네이버 지도보다 훨씬 사이트마다 구조가 제각각입니다. 정확도가
아직 실험 단계라서, 결과가 이상하면 터미널에 나오는 "[디버그]" 내용을 복사해서
보내주시면 계속 다듬어드릴게요.

## 문제 해결

- **"pip를 찾을 수 없습니다" 같은 오류**: 1번 단계에서 파이썬 설치 시 "Add to PATH"를
  체크했는지 확인하고, 터미널을 껐다가 다시 켜보세요.
- **`start.bat`을 더블클릭했는데 브라우저 탭이 안 뜨는 경우**: 처음 실행할 때는
  설치 때문에 검정 화면(cmd 창)이 몇 분 정도 떠 있는 게 정상입니다 - 기다려보세요.
  그 화면도 없이 아예 아무 반응이 없다면, 오류가 나서 화면이 바로 닫혔을 수
  있어요. 이 경우 폴더 안 `.setup_done`이라는 파일을 지우고(있다면) 다시
  더블클릭해보거나, 터미널에서 `python launcher.py`를 직접 입력해서 실행하면
  오류 내용이 그대로 보이니, 그 내용을 복사해서 보내주세요.
- **`start.bat`을 다시 눌렀는데 새 탭이 안 열리고 아무 반응이 없는 경우**: 이전에
  켰던 프로그램이 "종료" 버튼을 안 눌러서 뒤에서 계속 켜져 있는 상태일 수 있어요.
  브라우저에서 새 탭을 열고 주소창에 `http://127.0.0.1:8899/`를 직접 입력해보세요.
  화면이 뜨면 정상입니다. 완전히 새로 시작하고 싶으면 작업 관리자에서
  "pythonw.exe"를 찾아 종료한 뒤 다시 `start.bat`을 눌러주세요.
- **브랜드로만 검색하면 지역+키워드로 검색할 때보다 느린 경우**: 네이버 지도는
  브랜드명만으로 검색하면 목록 카드에 리뷰 수를 아예 안 보여줍니다. 그래서 이
  경우엔 기준 리뷰 수로 미리 거르지 못하고 항목을 하나하나 클릭해서 확인해야 해서
  지역+키워드 검색보다 느립니다 (정상입니다). 그래도 결과가 이상하면 "(목록에
  리뷰 수가 안 보여서 클릭해서 확인함 디버그)" 출력 내용을 복사해서 보내주세요.
- **"목록이 잘 읽히는지 확인용" 디버그에서 가게 이름이 이상하게 나오는 경우**: 그
  출력 내용을 복사해서 보내주시면 이름을 잘라내는 방식을 다듬어드릴게요.
- **찾은 가게 수가 너무 적은 경우**: `config.py`의 `MAX_LIST_PAGES`를 늘려서 목록을
  더 많이 불러오게 하거나, `PRODUCT_GROUPS`에 검색어를 더 추가해보세요.
- **"다음 페이지 버튼을 찾지 못했습니다"가 마지막 페이지 전에 나오는 경우**: 다음
  페이지 버튼의 실제 모양을 제가 추측으로 찾고 있어서 그럴 수 있어요. 화면(스크린샷)이나
  그 부분 출력 내용을 보내주시면 정확하게 고쳐드릴게요.
- **"캡차(사람 인증)를 띄웠습니다" 메시지가 나오는 경우**: 네이버가 자동화 프로그램으로
  의심해서 사람 확인 화면을 띄운 것입니다. `config.py`에서 `HEADLESS = False`로 바꾸고
  다시 실행하면 브라우저 창이 뜨는데, 거기서 캡차를 직접 한 번 풀어주세요. 프로그램이
  실행되는 폴더 안에 `browser_profile`이라는 폴더가 자동으로 생기는데, 여기에 로그인/방문
  기록이 저장되어서 한 번 풀고 나면 다음부터는 잘 안 뜹니다. 그래도 계속 뜨면 시간을
  두었다가 다시 시도해보세요.
- **대표 리뷰/카테고리/네이버지도주소가 이상하거나 비어있는 경우**: 목록 화면 글자만 보고
  추정하는 방식이라 완벽하지 않을 수 있어요. "목록이 잘 읽히는지 확인용" 디버그
  내용을 복사해서 보내주시면 추출 방식을 다듬어드릴게요.
