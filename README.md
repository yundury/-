# 강남구 한식당 리뷰 1000개 이상 검색기

네이버 지역검색 API로 특정 지역(기본값: 강남구)의 한식당을 찾고, 각 가게의
네이버 플레이스 페이지에서 리뷰 개수를 확인해서 **리뷰 1000개 이상인 가게만**
엑셀 파일로 정리해주는 프로그램입니다.

코딩을 몰라도 따라할 수 있도록 순서대로 설명합니다. 순서대로 하나씩만 하시면 됩니다.

---

## 0. 미리 알아둘 것

- 이 프로그램은 **네이버 지역검색 API(공식)** 로 가게 목록을 가져오고,
  **네이버 지도 웹페이지를 직접 열어서** 리뷰 개수를 읽어옵니다. 후자는 네이버가
  공식적으로 제공하는 기능이 아니라서, 나중에 네이버가 지도 화면을 바꾸면
  이 부분이 작동하지 않을 수 있습니다. 그럴 땐 다시 알려주시면 고쳐드릴게요.
- 리뷰 개수는 네이버 플레이스 페이지 상단에 표시되는 "리뷰 N" 숫자를 그대로 가져옵니다
  (예: "리뷰 1.1만" → 11000). 네이버가 화면 표기 방식을 바꾸면 이 부분도 같이 손봐야 할 수 있습니다.
- 지역검색 API는 검색어 1번에 최대 5개 가게만 알려주고 더 보기 기능이 없어서,
  `config.py`에 있는 동네 목록과 검색어를 조합해 여러 번 검색합니다. 더 많이 찾고
  싶으면 `config.py`의 `NEIGHBORHOODS`, `KEYWORDS` 목록을 늘리면 됩니다.
- 서버에 너무 빠르게 요청하지 않도록 자동으로 잠깐씩 쉬면서 실행되므로, 가게 수가
  많으면 시간이 좀 걸립니다 (가게당 약 2~4초).

---

## 1. 파이썬(Python) 설치하기

이미 설치되어 있다면 이 단계는 건너뛰세요.

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 버튼 클릭해서 설치 파일 받기
3. 설치 파일 실행 시, **맨 아래 "Add python.exe to PATH" (또는 "Add Python to PATH")
   체크박스를 꼭 체크**한 뒤 "Install Now" 클릭
4. 설치 확인: 터미널(아래 2번 참고)을 열고 아래 명령어 입력
   ```
   python --version
   ```
   버전 번호(예: Python 3.12.1)가 나오면 성공입니다.

---

## 2. 터미널(명령 프롬프트) 여는 법

- **Windows**: 시작 메뉴에서 "cmd" 또는 "명령 프롬프트" 검색 후 실행
- **Mac**: `Cmd + Space` 누르고 "터미널(Terminal)" 검색 후 실행

---

## 3. 이 프로그램 파일들을 폴더에 준비하기

`config.py`, `naver_restaurant_scraper.py`, `requirements.txt` 세 파일을
컴퓨터의 한 폴더(예: `내문서\naver-scraper`)에 모아두세요.

터미널에서 그 폴더로 이동합니다. 예:
```
cd C:\Users\사용자이름\Documents\naver-scraper
```
(Mac이라면 예: `cd /Users/사용자이름/Documents/naver-scraper`)

---

## 4. 필요한 프로그램 설치하기

터미널에 아래 두 줄을 순서대로 입력하고 엔터를 누르세요.

```
pip install -r requirements.txt
```

설치가 끝나면 아래 명령어도 입력하세요 (리뷰 개수를 읽어올 때 쓰는 브라우저를
설치하는 명령어입니다. 시간이 조금 걸릴 수 있어요):

```
playwright install chromium
```

---

## 5. 네이버 API 키 발급받기

지역검색 API를 쓰려면 네이버에서 발급하는 "Client ID"와 "Client Secret"이
필요합니다. 무료이고 몇 분이면 됩니다.

1. https://developers.naver.com/main/ 접속 후 네이버 아이디로 로그인
2. 오른쪽 위 또는 상단 메뉴에서 **"Application" → "애플리케이션 등록"** 클릭
   (또는 로그인 후 뜨는 "내 애플리케이션" 페이지에서 "애플리케이션 등록" 클릭)
3. **애플리케이션 이름**: 아무 이름이나 입력 (예: "한식당검색기")
4. **사용 API** 목록에서 **"검색"** 을 찾아 체크
5. **비로그인 오픈 API 서비스 환경** 항목에서 **"WEB 설정"** 선택
6. **웹 서비스 URL** 입력란에 아무 주소나 입력 (개인 테스트용이라 실제 사이트가
   없어도 됩니다. 예: `http://localhost:3000`)
7. **등록하기** 클릭
8. 등록이 끝나면 화면에 **Client ID**와 **Client Secret**이 나타납니다. 이 두
   값을 복사해두세요.

---

## 6. 발급받은 키를 프로그램에 입력하기

`config.py` 파일을 메모장(또는 아무 텍스트 편집기)으로 열어서 아래 두 줄을 찾은 뒤,

```python
NAVER_CLIENT_ID = "여기에_발급받은_Client_ID를_붙여넣으세요"
NAVER_CLIENT_SECRET = "여기에_발급받은_Client_Secret을_붙여넣으세요"
```

따옴표 안의 내용만 방금 복사한 값으로 바꾸고 저장하세요. 예:

```python
NAVER_CLIENT_ID = "AbCdEfGhIjKlMnOp"
NAVER_CLIENT_SECRET = "QrStUvWx"
```

필요하면 같은 파일에서 검색 지역(`DISTRICT`), 최소 리뷰 개수(`MIN_REVIEW_COUNT`),
결과 파일명(`OUTPUT_FILE`)도 바꿀 수 있습니다.

---

## 7. 실행하기

터미널에서 (아직 그 폴더에 있어야 합니다) 아래 명령어를 입력하세요.

```
python naver_restaurant_scraper.py
```

실행되면 검색 진행 상황이 화면에 하나씩 출력됩니다. 가게 수가 많으면
몇 분 정도 걸릴 수 있습니다.

---

## 8. 결과 확인하기

실행이 끝나면 같은 폴더 안에 엑셀 파일이 생깁니다.
(기본 파일명: `강남구_한식당_리뷰1000개이상.xlsx`)

파일을 더블클릭해서 엑셀로 열면 됩니다. 컬럼은 **가게이름, 주소, 카테고리, 리뷰개수**
입니다.

## 문제 해결

- **"pip를 찾을 수 없습니다" 같은 오류**: 1번 단계에서 파이썬 설치 시 "Add to PATH"를
  체크했는지 확인하고, 터미널을 껐다가 다시 켜보세요.
- **API 관련 오류(401 등)**: `config.py`의 Client ID/Secret이 정확히 복사되었는지
  확인하세요 (앞뒤 공백 없이).
- **리뷰 수가 계속 "찾지 못함"으로 나오는 경우**: `config.py`에서 `HEADLESS = False`로
  바꾼 뒤 다시 실행하면 브라우저 창이 실제로 뜨는 걸 볼 수 있어요. 어떤 화면에서
  멈추는지 알려주시면 코드를 수정해드릴게요.
- **검색되는 가게 수가 너무 적은 경우**: `config.py`의 `NEIGHBORHOODS`나 `KEYWORDS`
  목록에 더 많은 동네/키워드를 추가해보세요.
