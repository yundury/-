# 강남구 맛집 리뷰 1000개 이상 검색기

네이버 지도에서 특정 지역(기본값: 강남구) + 원하는 음식 종류로 검색한 뒤, 검색
결과 목록을 스크롤해서 최대한 많이 불러오고, 그 중 **리뷰 1000개 이상인 가게만**
보기 좋게 정리된 엑셀 파일로 저장해주는 프로그램입니다.

**네이버 API 키가 필요 없습니다.** 네이버 지도 화면을 직접 검색/스크롤해서
정보를 가져오는 방식이라 API 신청 절차가 아예 없어요.

코딩을 몰라도 따라할 수 있도록 순서대로 설명합니다. 순서대로 하나씩만 하시면 됩니다.

---

## 0. 미리 알아둘 것

- 이 프로그램은 **네이버 지도 웹페이지를 직접 열어서** 목록/상세 정보를 읽어옵니다.
  네이버가 공식적으로 제공하는 기능이 아니라서, 나중에 네이버가 화면 구조를 바꾸면
  이 부분이 작동하지 않을 수 있습니다. 그럴 땐 다시 알려주시면 고쳐드릴게요.
- 동작 순서: `지역 + 음식종류`로 검색해서 목록을 스크롤해 최대한 불러오고,
  **브랜드명/리뷰수/대표 리뷰는 목록 화면 글자에서 바로 뽑습니다.** 그 중
  **리뷰 수가 기준을 넘는 항목만 그 자리에서 클릭**해서 옆에 뜨는 상세 패널에서
  정확한 카테고리와 실제 지도 링크를 가져옵니다 (페이지를 새로 열지 않고 이미
  열려있는 목록에서 바로 클릭하는 거라, 기준 미달 가게가 안 넘어가면 상세 페이지에
  아예 안 들어가는 것보다는 조금 느리지만 예전 방식보다는 훨씬 빠릅니다).
  (주소는 목록/상세 화면 글자만으로는 진짜 주소인지 홍보 문구인지 구분이 잘 안 돼서 뺐습니다.)
- 대표 리뷰도 AI 요약이 아니라 목록에 보이는 리뷰 후기 한 줄을 그대로 가져온
  것입니다. 실행하면 처음에 "목록이 잘 읽히는지 확인용" 디버그가 나오는데,
  카테고리나 지도 링크가 이상해 보이면 복사해서 보내주세요.
- 서버에 너무 빠르게 요청하지 않도록 자동으로 잠깐씩 쉬면서 실행되므로, 가게 수가
  많으면 시간이 좀 걸립니다.

## 1. 파이썬(Python) 설치하기

이미 설치되어 있다면 이 단계는 건너뛰세요.

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 버튼 클릭해서 설치 파일 받기
3. 설치 파일 실행 시, **맨 아래 "Add python.exe to PATH" (또는 "Add Python to PATH")
   체크박스를 꼭 체크**한 뒤 "Install Now" 클릭
4. 설치 확인: 터미널(아래 2번 참고)을 열고 아래 명령어 입력
   ```
   python --version
   ```
   버전 번호(예: Python 3.12.1)가 나오면 성공입니다.

---

## 2. 터미널(명령 프롬프트) 여는 법

- **Windows**: 시작 메뉴에서 "cmd" 또는 "명령 프롬프트" 검색 후 실행
- **Mac**: `Cmd + Space` 누르고 "터미널(Terminal)" 검색 후 실행

---

## 3. 이 프로그램 파일들을 폴더에 준비하기

`config.py`, `naver_restaurant_scraper.py`, `launcher.py`, `requirements.txt`,
`실행.bat` 다섯 파일을 컴퓨터의 한 폴더(예: `내문서\naver-scraper`)에 모아두세요.

터미널에서 그 폴더로 이동합니다. 예:
```
cd C:\Users\사용자이름\Documents\naver-scraper
```
(Mac이라면 예: `cd /Users/사용자이름/Documents/naver-scraper`)

---

## 4. 필요한 프로그램 설치하기

터미널에 아래 명령어를 입력하고 엔터를 누르세요.

```
pip install -r requirements.txt
```

설치가 끝나면 아래 명령어도 입력하세요 (네이버 지도를 읽어올 때 쓰는 브라우저를
설치하는 명령어입니다. 시간이 조금 걸릴 수 있어요):

```
playwright install chromium
```

---

## 5. 검색 조건 설정하기

`config.py` 파일을 메모장(또는 아무 텍스트 편집기)으로 열어서, 원하는 대로 바꾸세요.

- `DISTRICT`: 검색할 지역 (예: `"강남구"`)
- `PRODUCT_GROUPS`: 찾고 싶은 음식 종류를 자유롭게 리스트로 적으세요. 네이버 지도에
  검색했을 때 실제로 결과가 나오는 말이면 뭐든 됩니다. 예: `["한식"]`,
  `["퓨전한식", "고깃집"]`
- `MIN_REVIEW_COUNT`: 최종적으로 남길 최소 리뷰 개수
- `OUTPUT_FILE`: 결과 엑셀 파일 이름
- `MAX_LIST_PAGES`: 검색 결과 목록(페이지 1, 2, 3...)을 최대 몇 페이지까지 넘겨가며
  불러올지 (늘리면 더 많이 찾지만 오래 걸림)
- `HEADLESS`: 브라우저 창을 화면에 보이게 할지 여부 (자세한 설명은 파일 안 주석 참고)

## 6. 실행하기

이제 매번 `config.py`를 열어서 지역/검색어/리뷰수를 고칠 필요 없이, 입력창이 있는
작은 프로그램(`launcher.py`)으로 실행할 수 있습니다.

**가장 쉬운 방법**: 폴더 안의 `실행.bat` 파일을 그냥 더블클릭하세요. cmd 창을 열고
명령어를 입력할 필요 없이 바로 입력창이 뜹니다. (원하면 이 파일의 바로가기를
만들어서 바탕화면에 두면 다음부터 더 편하게 켤 수 있어요 - 파일 오른쪽 클릭 →
"바로 가기 만들기".)

터미널에서 직접 실행하고 싶다면 (아직 그 폴더에 있어야 합니다) 아래 명령어를
입력하세요.

```
python launcher.py
```

어느 방법으로 실행하든 작은 창이 뜨면 **지역**(예: 강남구), **키워드**(예: 한식 -
여러 개는 콤마로 구분, 예: `한식, 고깃집`), **희망 리뷰 수**를 입력하고 "실행"
버튼을 누르세요. 진행 상황이 창 안에 그대로 출력됩니다. 가게 수가 많으면 몇 분
정도 걸릴 수 있습니다.

(참고: `config.py`에 있는 `MAX_LIST_PAGES`, `HEADLESS` 같은 값은 그대로
적용됩니다. 이 값들은 자주 안 바꾸는 값이라 입력창에는 없어요. `config.py`에서
직접 바꾸면 됩니다.)

터미널에 직접 명령어를 입력하는 방식(예전 방식)도 여전히 됩니다. 이 경우
`config.py`에서 지역/검색어/리뷰수를 직접 바꾼 뒤 아래처럼 실행하면 됩니다.

```
python naver_restaurant_scraper.py
```

## 7. 결과 확인하기

실행이 끝나면 프로그램이 있는 폴더 안의 **`Excel` 폴더**(없으면 자동으로 만듭니다)
안에 엑셀 파일이 생깁니다. `launcher.py`로 실행했다면 입력한 지역/검색어/리뷰수와
크롤링한 날짜에 맞춰 파일 이름이 자동으로 정해집니다
(예: `강남구_한식_리뷰1000개이상_250115.xlsx`, 맨 뒤 숫자는 `년월일` 두 자리씩).
같은 이름의 파일이 이미 있으면(같은 조건으로 같은 날 또 실행한 경우 등) 기존
파일을 덮어쓰지 않고 `(1)`, `(2)`처럼 번호를 붙여서 따로 저장합니다.

파일을 더블클릭해서 엑셀로 열면 됩니다. 컬럼은 **브랜드명, 키워드, 카테고리,
리뷰수, 대표 리뷰, 네이버지도주소** 순서입니다. (키워드는 config.py에서 검색에 쓴
음식 종류, 네이버지도주소는 클릭하면 바로 그 가게의 지도 페이지로 이동하는
링크입니다. 브랜드명/키워드/카테고리/리뷰수 칸은 가운데 정렬되어 있습니다.)

보기 편하도록 1행(헤더)은 회색 배경, 전체 글꼴은 '나눔바른고딕OTF'로 되어 있고,
열 너비/행 높이도 내용에 맞춰 자동으로 조정됩니다. 만약 컴퓨터에 '나눔바른고딕OTF'
글꼴이 설치되어 있지 않으면 엑셀이 다른 글꼴로 대신 보여줄 수 있는데, 이 경우
"네이버 나눔글꼴"을 검색해서 무료로 설치하시면 됩니다.

## 문제 해결

- **"pip를 찾을 수 없습니다" 같은 오류**: 1번 단계에서 파이썬 설치 시 "Add to PATH"를
  체크했는지 확인하고, 터미널을 껐다가 다시 켜보세요.
- **`실행.bat`을 더블클릭했는데 아무 창도 안 뜨는 경우**: `실행.bat`은 검정 화면이
  안 남게 조용히 실행되는 방식이라, 오류가 나도 화면에 안 보일 수 있어요. 이 경우
  터미널에서 `python launcher.py`를 직접 입력해서 실행하면 오류 내용이 그대로
  보이니, 그 내용을 복사해서 보내주세요.
- **"목록이 잘 읽히는지 확인용" 디버그에서 가게 이름이 이상하게 나오는 경우**: 그
  출력 내용을 복사해서 보내주시면 이름을 잘라내는 방식을 다듬어드릴게요.
- **찾은 가게 수가 너무 적은 경우**: `config.py`의 `MAX_LIST_PAGES`를 늘려서 목록을
  더 많이 불러오게 하거나, `PRODUCT_GROUPS`에 검색어를 더 추가해보세요.
- **"다음 페이지 버튼을 찾지 못했습니다"가 마지막 페이지 전에 나오는 경우**: 다음
  페이지 버튼의 실제 모양을 제가 추측으로 찾고 있어서 그럴 수 있어요. 화면(스크린샷)이나
  그 부분 출력 내용을 보내주시면 정확하게 고쳐드릴게요.
- **"캡차(사람 인증)를 띄웠습니다" 메시지가 나오는 경우**: 네이버가 자동화 프로그램으로
  의심해서 사람 확인 화면을 띄운 것입니다. `config.py`에서 `HEADLESS = False`로 바꾸고
  다시 실행하면 브라우저 창이 뜨는데, 거기서 캡차를 직접 한 번 풀어주세요. 프로그램이
  실행되는 폴더 안에 `browser_profile`이라는 폴더가 자동으로 생기는데, 여기에 로그인/방문
  기록이 저장되어서 한 번 풀고 나면 다음부터는 잘 안 뜹니다. 그래도 계속 뜨면 시간을
  두었다가 다시 시도해보세요.
- **대표 리뷰/카테고리/네이버지도주소가 이상하거나 비어있는 경우**: 목록 화면 글자만 보고
  추정하는 방식이라 완벽하지 않을 수 있어요. "목록이 잘 읽히는지 확인용" 디버그
  내용을 복사해서 보내주시면 추출 방식을 다듬어드릴게요.
